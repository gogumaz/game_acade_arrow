## 2. 제품 정의

### 2.1 한 문장 설명

**얽힌 화살표 사슬 더미에서 진로가 열린 사슬을 찾아 화살촉 방향으로 빼내고, 막힌 사슬을 잘못 골라 하트를 다 잃기 전에 보드를 전부 비우는 싱글 세션 슬라이드 퍼즐 게임이다.**

### 2.2 장르 포지셔닝

- 장르: 슬라이드 아웃 / 언블록 계열 (Arrow Out · Pull the Pin · Unblock Me와 인접). 이동이 아니라 **제거**가 목표이고, 제거 방향이 오브젝트 자체(화살촉)에 각인되어 있다는 점이 특징이다.
- 세션 구조: 한 판 완결형. 영상 기준 최고 난이도 한 판이 2분 30초 — 오락실 1크레딧 세션 길이(3~5분)와 잘 맞는다.
- 조작 난이도: 선택 1종. 진입 장벽이 극히 낮고, 난이도는 **사슬의 밀도·길이·얽힘 순서**에서 나온다.
- 원작에는 점수·시간이 없어 순수 퍼즐(젠 계열)에 가깝다. 아케이드화하려면 점수·시간·크레딧 층을 새로 설계해야 한다 (6장·10장).

### 2.3 플레이 판타지

- 빽빽한 실뭉치에서 "지금 당장 빠지는 실"을 찾아내는 관찰의 재미.
- 사슬이 기차처럼 자기 몸을 따라 화면 밖으로 쭉 빠져나가는 해방감.
- 실수하면 빨간 낙인이 남고 하트가 줄어드는 압박 속에서, 잘못 고른 사슬의 진로를 뚫어 주는 되갚기.
- 종반으로 갈수록 보드가 비어 가며 제거 템포가 가속되는 청소 쾌감.

### 2.4 설계 기둥

1. **한 손, 한 규칙** — 선택 + 화살촉 방향 제거 외의 규칙을 코어에 추가하지 않는다.
2. **보이는 실수** — 잘못 고른 사슬은 빨갛게 남아 다음 판단의 단서가 된다. 실패는 숨기지 않고 보드 위에 기록한다.
3. **짧고 완결된 세션** — 한 판은 수십 초~수 분 안에 명확한 성공/실패로 끝난다.
4. **밀도가 곧 난이도** — 새 규칙 없이 사슬 수·길이·얽힘으로만 난이도를 조절한다.

## 3. 코어 메커니즘

### 3.2 기본 규칙

1. 플레이어는 보드의 사슬 1개를 선택한다. `확인`
2. 선택된 사슬은 화살촉 방향으로 **자기 경로를 따라** 전진하며, 진로에 다른 사슬이 없으면 화면 밖까지 미끄러져 제거된다. `확인`
3. 진로에 다른 사슬의 선분이 있으면 제거되지 않고 **빨간색으로 표시**되며 **하트가 1개 감소**한다. `확인`
4. 빨간 사슬은 진로가 열린 뒤 다시 선택하면 정상 제거된다. `추정`
5. 상단 하트가 0이 되면 실패한다. `추정(장르 표준)`

### 3.3 진로 판정 (`추정` — 구현 시 확정 필요)

- 사슬 S의 진로 = S가 화살촉 방향으로 1칸씩 전진할 때 S의 모든 선분이 지나가는 격자 선분의 합집합 (S가 보드 밖으로 완전히 나갈 때까지).
- 진로 위에 다른 사슬 T의 선분이 하나라도 있으면 "막힘". 영상 01:10의 빨간 사슬은 화살촉(←) 진로에 세로 선분 1개가 있어 막혔다.
- 진로 판정 시점: 선택 즉시 (막힘이면 즉시 빨간 표시). 전진 도중 충돌 판정이 아니라 선택 시점 일괄 판정으로 보인다 (빨간 사슬이 조금도 움직이지 않음).
- 사슬끼리 교차/접촉 배치 여부: 영상에서 사슬들이 격자 위에서 서로 밀접하게 지나가지만 겹치지는 않는 것으로 보임 → **선분 단위 배타 점유**로 추정.

### 3.4 종료 조건

| 조건 | 결과 | 근거 |
|---|---|---|
| 보드의 모든 사슬 제거 | 클리어 → 클리어 문구 + 색종이 연출 | 확인 |
| 하트 0 | 실패 (재시작/이어하기 분기) | 추정 — 영상에 실패 장면 없음. 자체 결정 필요 |
| 시간/이동 제한 | 영상 근거 없음. 도입 여부는 미확정 (아케이드화 시 신설 검토, 6장·10장) | 미확정 |

### 3.5 조작

- 원작: 터치(탭 또는 드래그) 1종. `추정`
- 본 프로젝트의 **레버 + 2버튼** 조작계로 각색 시 "사슬 선택 커서" 이동 방식이 핵심 설계 과제다. → 10장, 11장 열린 질문.
