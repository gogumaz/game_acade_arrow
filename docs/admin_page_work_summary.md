## 1. 작업 목적

기존 관리자 페이지 기능 문서를 바탕으로 NEON GRID 오락실 아케이드 게임에 맞는 **상용 수준의 업주용 관리자 페이지 기획서**를 작성했다.

단순한 설정 목록이 아니라 실제 영업 기기에서 다음 업무를 수행할 수 있는 운영 사양을 목표로 했다.

- 유료·이벤트 플레이와 크레딧 현황 확인
- 가격, 볼륨, 초기 하트 설정
- 스테이지 수치와 8×20 초기 맵 편집
- 무료 테스트 플레이와 밸런스 검증
- 코인·입력·사운드·화면·Serial I/O 진단
- 설정과 운영 데이터의 안전한 저장·복구
- 위험 작업의 오조작 방지와 변경 이력 추적
- 영업 시작·종료 및 장애 발생 시 현장 대응

## 5. 주요 기획 결정

### 5.1 관리자 페이지의 성격

플레이어용 옵션이 아닌 코인 도어 안쪽의 **Operator/Service Menu**로 정의했다. 출시판은 물리 SERVICE 신호를 기본 진입 수단으로 사용하고 개발 키 F9는 비활성화한다.

### 5.2 코인과 매출 보호

관리자 화면과 테스트 플레이 중 들어온 실제 코인을 무시하지 않고 유료 크레딧에 정상 적립하도록 정의했다. 플레이 수와 실제 코인 펄스는 다른 지표이므로 각각 기록한다.

### 5.3 위험 작업

통계 초기화, 전체 스테이지 복원, 앱 재시작은 단순한 버튼 2회 입력이 아니라 대상과 현재값을 확인한 뒤 H를 일정 시간 유지해야 실행되도록 정의했다.

### 5.4 편집 작업 사본

스테이지 수치, 맵, 단일 스테이지 복원은 실제 운영 데이터에 즉시 반영하지 않는다. 검증과 명시적인 저장을 통과한 작업 사본만 라이브 데이터로 반영한다.

### 5.5 저장 실패

저장 실패를 콘솔 오류로 끝내지 않고 관리자 화면에 표시한다. 저장이 실패하면 메인이나 OS 종료로 이동하지 않으며 재시도와 저장소 진단을 제공한다.

### 5.6 현장 진단

외부 키보드나 개발 도구 없이 P1/P2 입력, 코인 펄스, 사운드 채널, 화면 패턴, Serial 연결, 파일 저장을 점검할 수 있도록 했다.
